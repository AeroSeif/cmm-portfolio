Position / profile evaluation is performed from the measured features in the established datum reference frame; CAD values remain nominal references, not measured results.
ENGINEERING LOGIC

The CAD model was used to derive the nominal centre coordinates of the hole features relative to the component datum structure. These nominal XYZ values were then used to create corresponding reference points in Aberlink 3D.

Those references supported construction of the planes needed to relate measured circles on the curved/contoured geometry to the intended inspection definition.

01 / DATUM-BASED COORDINATE SYSTEM

The inspection coordinate system was established from the drawing's datum reference structure. Correct alignment provides the reference frame against which positional requirements are evaluated.

02 / CONSTRUCTED REFERENCE PLANES

CAD-derived nominal points were used in Aberlink to construct reference geometry. This allowed measured circular features to be related to the appropriate geometric reference.

03 / HOLES ON CURVED GEOMETRY

The holes were measured as circles and related/projected to the constructed planes rather than treating the contoured surface as inherently planar.

04 / POSITIONAL TOLERANCE

The hole pattern included position requirements; the program therefore needed correct datum referencing and nominal-location comparison without exposing drawing-specific values.

PROBE ACCESS & PATH PLANNING
Probe orientation → stylus accessibility → approach direction → feature access → collision clearance → measurement sequence. The component required physical elevation on the fixture so underside datum/reference surfaces could be reached and measured rather than relying on the granite table as a substitute reference. The curved geometry also required deliberate approach and collision-avoidance planning around the internal features.
